## ⎡ ABOUT ⎦

Este é meu portfólio pessoal, criado para apresentar meus projetos e minha trajetória como estudante de desenvolvimento **back-end**.

A interface foi desenvolvida com **React e TypeScript**, com foco em uma identidade visual escura, superfícies translúcidas e adaptação a diferentes tamanhos de tela. Os projetos incluem uma breve descrição, tecnologias utilizadas e links para os respectivos repositórios.

## ⎡ FEATURES ⎦

- Apresentação pessoal e seção de habilidades
- Vitrine de projetos com tecnologias e descrições
- Página de detalhes para cada projeto, com links para o GitHub
- Navegação por fragmentos de URL
- Contato por e-mail, com opção de copiar o endereço
- Layout responsivo e suporte à preferência por movimento reduzido

## ⎡ GETTING STARTED ⎦

**Pré-requisitos**

- [Node.js](https://nodejs.org/) versão 20.19.x ou 22.12.0 e superiores
- [Git](https://git-scm.com/)

<br/>

**1 · Clonar o repositório**

```bash
git clone https://github.com/gustavoverenka/portfolio.git
cd portfolio
```

**2 · Instalar as dependências**

```bash
npm install
```

**3 · Iniciar o ambiente de desenvolvimento**

```bash
npm run dev
```

Abra o endereço local exibido no terminal. No Windows, caso o PowerShell bloqueie `npm`, use `npm.cmd install` e `npm.cmd run dev`.

**4 · Gerar e visualizar a versão de produção**

```bash
npm run build
npm run preview
```

O comando de build verifica o TypeScript e gera os arquivos finais na pasta `dist/`.
